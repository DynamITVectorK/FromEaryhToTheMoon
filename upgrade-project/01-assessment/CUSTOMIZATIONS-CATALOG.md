# Catálogo de Personalizaciones NAV 2016

> **Versión:** 1.0 | **Fecha:** [COMPLETAR] | **Responsable:** [COMPLETAR]

---

## Propósito

Documentar detalladamente cada personalización realizada sobre el estándar de NAV 2016, clasificándola por módulo, complejidad, tipo de cambio y estrategia de migración a Business Central SaaS. Este catálogo es la base para la planificación del desarrollo AL.

---

## Leyenda de Tipos de Personalización

| Tipo | Descripción |
|------|-------------|
| **NEW-TABLE** | Nueva tabla custom creada (rango 50000+) |
| **MOD-TABLE** | Modificación de tabla estándar (campos añadidos) |
| **NEW-PAGE** | Nueva página o lista custom |
| **MOD-PAGE** | Modificación de página estándar (nuevos controles, acciones) |
| **NEW-CU** | Nueva codeunit con lógica de negocio |
| **MOD-CU** | Modificación de codeunit estándar |
| **NEW-REPORT** | Nuevo reporte custom |
| **MOD-REPORT** | Modificación de reporte estándar |
| **NEW-XMLPORT** | Nuevo XMLPort para integraciones |
| **NEW-QUERY** | Nueva query |
