# Output

Este directorio contiene artefactos generados por los scripts de assessment diferencial:

- `standard/` y `customer/`: objetos NAV separados en ficheros individuales.
- `differential-inventory.csv`: baseline tabular para clasificación y filtro.
- `differential-inventory.md`: versión legible del baseline.

El contenido es preliminar y debe revisarse por arquitecto NAV/BC antes de estimación o conversión AL.
