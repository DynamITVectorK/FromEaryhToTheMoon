# 08-training

Esta carpeta contiene los entregables de formación para la adopción de Business Central SaaS tras el upgrade desde NAV 2016.

## Objetivos

- Asegurar que usuarios clave y usuarios finales puedan operar en BC SaaS.
- Reducir incidencias post-go-live por falta de capacitación.
- Estandarizar materiales y sesiones por rol.

## Documentos incluidos

- `TRAINING-PLAN.md`: planificación de audiencias, calendario, contenidos y métricas.
- `SUPER-USER-GUIDE.md`: guía operativa para usuarios clave.
